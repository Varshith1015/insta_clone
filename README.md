Instagram UI Clone

A static Instagram-inspired user interface built using HTML and CSS. This project recreates the visual structure of an Instagram feed, including the sidebar navigation, stories section, user suggestions, posts, post actions, and profile information.

🌐 Live Demo

GitHub Pages:
(https://varshith1015.github.io/insta_clone/)

📌 About the Project

This project is a front-end recreation of the Instagram desktop interface. It focuses on building the layout and visual appearance using HTML5 and CSS3, without using JavaScript or a front-end framework.

The page includes a fixed-style sidebar navigation, stories, Instagram-style posts, user profile information, suggestions, and footer links.

✨ Features
Instagram-style sidebar navigation
Instagram logo and navigation icons
Stories section with circular story images
User profile section
"Suggestions for you" section
Follow and switch account links
Instagram-style post layout
User verification badge
Like, comment, share, and save buttons
Post likes and comments information
Post caption and translation option
Add comment section
Instagram-style footer links
Responsive behavior for smaller screens
🛠️ Technologies Used
HTML5
CSS3
Google Fonts – Roboto
SVG assets

🚀 How to Run Locally

No installation or dependencies are required.

1. Clone the repository
git clone (https://github.com/Varshith1015/insta_clone.git)
2. Open the project

Navigate into the project directory:

cd YOUR-REPOSITORY
3. Run the project

Simply open index.html in your web browser.

You can also use VS Code with the Live Server extension to run the project locally.
